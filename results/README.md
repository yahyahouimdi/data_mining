# Results

Generated by the scripts in `scripts/`; nothing here is written by hand. The
models were trained on 2026-10-12 with the datasets in `extracted_data/`.

| File | Written by | Content |
|---|---|---|
| `<dataset>/<model>_validation_metrics.json` | training scripts | selected hyperparameters, threshold, validation metrics, and every grid candidate |
| `<dataset>/<model>_test_metrics.json` | training scripts | test metrics and confusion matrix |
| `<dataset>/<model>_test_predictions.csv` | training scripts | label, prediction, and score of every test window |
| `<dataset>/<model>_training_history.csv` | `train_neural_models.py` | loss and validation F1 per epoch |
| `model_comparison.csv` | `compare_models.py` | all 36 runs, sorted by validation F1 |
| `best_per_model.csv` | `compare_models.py` | best training set of each model |
| `selected_model_report.json` | `compare_models.py` | selected model, test metrics, event-level report |
| `selected_model_predicted_intervals.csv` | `compare_models.py` | reconstructed seizure intervals |
| `selected_model_true_intervals.csv` | `compare_models.py` | annotated seizures, with detection status and start error |
| `selected_model_errors_by_recording.csv` | `compare_models.py` | TP, FP, FN, TN per test recording |
| `cross_validation_folds.csv`, `cross_validation_summary.csv` | `cross_validate_models.py` | grouped 5-fold check of the classical models |

Models are selected on validation F1, then validation recall. Test metrics are
reported once and never used for selection. The results are discussed in
`reports/questions_9_14_report.md`.
