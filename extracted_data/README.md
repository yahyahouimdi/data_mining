# Extracted data

Generated by `prepare_balanced_exports` and `create_stratified_group_cv_reports`; see the project README for the split and balancing policy.

- `window_<d>s_unbalanced.parquet`: every window with its `split` column.
- `window_<d>s_<method>/`: balanced training rows plus untouched validation and test rows.
- `window_<d>s_split_assignments.json`: recording to partition.
- `window_<d>s_cv_folds.csv`: development recording to cross-validation fold.
- `balancing_audit_report.csv`: class counts for every dataset.
