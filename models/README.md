# Models

Generated by `scripts/train_classical_models.py` and
`scripts/train_neural_models.py`, one folder per training set
(`window_<d>s_<method>/`).

- `<model>.joblib`: a dictionary with the fitted scikit-learn `pipeline`
  (imputation, scaling where used, model), the decision `threshold`, the
  `features` list, and the selected `params`.
- `<model>.pt`: a PyTorch checkpoint with the network `state_dict`, the fitted
  `imputer` and `scaler`, the `features` list, the `sequence_length`, and the
  decision `threshold`.

A window is predicted "seizure" when the model's score is at least the stored
threshold.
